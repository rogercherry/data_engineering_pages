# Data Engineering, One Byte at a Time

An accessible, bite-sized data engineering learning site built for GitHub Pages.

## Features

- Five plain-English terms each day
- Acronyms always shown with their full meaning
- A two-part daily quiz covering today’s terms and prior learning
- A searchable glossary of foundational data engineering concepts
- Local progress saving and an optional easier-reading mode

The site has no build step or external dependencies. Open `index.html` locally, or
serve the repository root with any static web server.

## GitHub Pages

In the repository settings, set **Pages → Build and deployment → Source** to
**Deploy from a branch**, then select the repository’s default branch and `/ (root)`.
